# Employee Leave Management Portal

## Project Overview
This project is a backend-based Employee Leave Management Portal developed using Python.

It allows employees to apply for leave and check their requests. The administrator can view, approve, and reject leave requests.

## Features
- Login system for employees and administrators
- Apply for leave
- View leave requests
- Search leave requests
- Approve or reject leave requests
- Generate leave reports
- Save records using JSON file handling
- Exception handling for invalid inputs

## Technologies Used
- Python
- Jupyter Notebook
- JSON
- GitHub

## How to Run
Run the Python program in Jupyter Notebook.
